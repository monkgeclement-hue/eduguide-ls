# Real Programme Data

This folder contains source-derived programme records grouped by institution.

Generated by:

```powershell
& 'C:\Users\lepha\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' scripts\scrape-real-programmes.py
```

Files:

- `summary.json` - institution counts and generation metadata
- `programmes.flat.json` - one flat list of all extracted records
- `programmes.by-institution.json` - records grouped by institution name
- `institutions/*.json` - one file per institution
- `source-coverage.json` - tracked links that are source-only, blocked, or useful for future manual review
- `source-audit.json` - every shared source link with status, extracted count, and shortage notes
- `shortages.md` - human-readable summary of missing data
- `fees/*.json` - manually extracted fee structures and fee evidence
- `handbooks/*.json` - manually extracted handbook rules and policy evidence

Important:

- These records are real source-derived data, not career/skill AI guesses.
- All records are marked `needs_admin_review` before they should become public canonical data.
- Some source pages are easier to parse than others. LUCT, Botho, CAS, CHE, and Lerotholi are clearer; NUL pages are richer but may contain duplicate or context-heavy programme headings that need admin review.
